For every ray that intersects an object, I check if the hit primitive is an emitter by looking up its index in the `scene.geometry.emitters_idx` tensor. For emitted radiance, I iterate through all of the emitters in the scene. For each emitter, I create a mask to find the rays that hit that particular emitter. The emitters own `radiance` value is then added to the `result` for the corresponding pixels. For reflected radiance, I first filter out all of the rays that hit an emitter so that we only look at the nonemitting surfaces. For each surface point, an emitter is chosen with uniform probability.
